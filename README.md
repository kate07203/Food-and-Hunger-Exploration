# Food-and-Hunger-Exploration
This project explores how hunger can change the appeal of food. It began with a personal observation: after missing lunch, eating two oranges felt especially satisfying. That experience led me to wonder whether food tastes better because of the food itself, our hunger, or the context in which we eat.
Through brainstorming, questioning assumptions, and considering alternative explanations, I developed a simple visual demo using HTML, CSS, and JavaScript. Moving a hunger slider changes the size of a halo around an orange, representing how appealing that food might feel.
The demo explores the assumption that greater hunger increases food’s appeal—it does not present this as a universal fact. It is a starting point for reflecting on the relationship between food, hunger, and satisfaction.

# Try the demo
Download the project and open taste-and-context/index.html in your browser. Move the hunger slider to watch the orange’s halo grow or shrink. No installation is required.
